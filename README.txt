THE VEIL — REIMAGINED
======================

1. Open this folder in WebStorm.
2. Open index.html in your browser (right click > Open in Browser).
3. Optional video background:
   Put an MP4 file in the images folder and name it forest.mp4
   The home page has a dark forest image fallback if you do not add a video.

Files:
- index.html  page structure and content
- style.css   visual design, animations and responsive layout
- script.js   loading screen, filters, case-file popups and signal interaction

The website uses Google Fonts and a few remote atmospheric photos, so an internet
connection improves the appearance. All text and entities are fictional.
